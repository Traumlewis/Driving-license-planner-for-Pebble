## Driving Planner 3.8.55

This release brings all 24 official EU interface languages to the phone and watch, compact storage, and the improvements developed since 3.8.4. One PBW supports all six native platforms.

### What’s new

- **24 complete interface languages:** German, English, Spanish, French, Italian, Portuguese, Dutch, Polish, Danish, Swedish, Finnish, Czech, Hungarian, Romanian, Slovak, Croatian, Slovenian, Estonian, Latvian, Lithuanian, Maltese, Irish, Greek and Bulgarian.
- **Downloads from GitHub:** the language list, phone settings and full watch menus/explanations use verified remote packets. The selected language remains available offline. Only one selected watch packet is persisted.
- **LP5 compression and script fonts:** seven frozen shared codebooks keep every current watch packet within 2,560 bytes. Greek and Cyrillic use additional resource-backed fonts; existing Latin-language designs and numeric fonts remain unchanged. Compatible translation edits can be published without rebuilding.
- **Compact storage:** appointments, progress and training profiles migrate in place, retain the booking journal and avoid redundant writes. Theory checks, protected totals, manual units and additional minutes are preserved.
- **Whole-unit editors:** practical lesson types without a statutory minimum use whole units. Their progress counters no longer offer irrelevant extra-minute hold actions. Required practical lessons retain five-minute duration steps; theory remains in 90-minute units.
- **Current language support:** only the current compatibility variant is hosted. All 24 current languages are retained; obsolete LP3/LP4 download folders were retired.

The app retains 24 appointments, two reminders, ten-minute snooze, lesson booking confirmation, all 16 German licence classes, protected theory checklists, optional phone entry and Pebble Timeline. Training rules remain those of **Germany** in every language.

### Supported watches

Time 2, Core 2 Duo, Round 2, Time / Time Steel, Pebble 2 / Pebble 2 SE and Time Round. Buttons work on every supported model; Time 2 and Round 2 also support touch. The original Pebble and Pebble Steel are not included.

### Installation and upgrade

1. Open **Fahrschul-Planer-v3.8.55.pbw** in the Pebble app and install over the existing app. **Do not uninstall first** if you want to retain your data.
2. Open the watch app and its phone settings with Internet and Bluetooth connected. Select a language and apply it to the watch. Initial installation and uncached language changes require this download.
3. After successful transfer, the selected watch language, appointments and progress remain usable offline.

The application UUID is unchanged. Compact storage migration is automatic. Downgrading to a pre-3.8.50 build requires the legacy-storage restore helper documented in `docs/DEV-3.8.50.md`; older language-download variants are no longer hosted.

### Validation

The release PBW is byte-for-byte identical to the tested 3.8.55 DEV PBW, with a regular release filename. All six SDK 4.44 emulator platforms passed 24-language replacement, offline restart and pre-upgrade data comparisons. Production phone-client tests downloaded the real GitHub packets and transferred them to a native emulator. Glyph, decoder, corruption/interruption, storage, browser and catalogue checks passed. These are emulator checks, not a claim of physical-watch certification.

The Pebble 2 emulator needed a direct QEMU installation with throttled transfer after its normal phone-simulator upload failed; the unchanged PBW then passed its complete native language/data tests. Details and memory measurements are in `docs/DEV-3.8.55.md` and `docs/memory-comparison-3.8.55.json`.
