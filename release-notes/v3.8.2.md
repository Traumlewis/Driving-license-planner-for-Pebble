## Driving Planner 3.8.2

Normal release by **Traumlewis**, consolidating the multi-device DEV series.

### Downloads

- **Fahrschul-Planer-v3.8.2.pbw** — install this on your watch through the Pebble app.
- **Quellcode.zip** — complete source code for all supported platforms.
- **Store-Assets.zip** — 720 × 320 banner, five native screenshots per watch model and English/German descriptions.
- **SHA256SUMS.txt** — checksums for the downloadable files.

### Supported watches

Time 2, Core 2 Duo, Round 2, Time / Time Steel, Pebble 2 / Pebble 2 SE and Time Round. One PBW contains all six platforms.

### Included

Up to 24 practical/theory appointments; two reminders; German licence classes and training profiles; required-lesson progress and theory checklists; optional phone settings and Pebble Timeline; English/German; device-adapted rectangular, monochrome and round layouts.

All device programs use version **3.8.2** and developer **Traumlewis**. The guide ends with the current version and **Idee by Traumlewis | Code by Codex**. The compact Time Round headings and corrected duration spacing are included.

Install over an existing copy without uninstalling first to retain data. UUID and storage format are unchanged. All six platforms were checked in native emulators; physical-watch testing was not performed for this release preparation.
