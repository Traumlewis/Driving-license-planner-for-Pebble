# Project preferences

- Maintain all six platforms through the five device projects. Use release.json and tools/sync_release.py for versions and credits.
- The current development version is 3.8.50; continue 3.8.51, 3.8.52, etc., following the owner’s version numbering.
- Source updates to GitHub are authorized. Create or publish a GitHub Release, or promote a test build to a normal release, only when the owner explicitly requests it. Source pushes must not trigger release publication.
- Provide a ready-to-test combined PBW after app changes. Test filenames must include (DEV). Use tools/build_all.py --output to keep test binaries outside the tracked release/ directory.
- Preserve user appointments, theory checkboxes, counters and extra minutes during updates. Normal release developer is Traumlewis; credits remain (Idee by Traumlewis | Code by Codex).

- Language packs: generate with tools/sync_release.py; see docs/DEV-3.8.49.md. Short translated strings use eight rolling buffers: copy text retained across draw callbacks. Only the selected LP4 watch packet is persisted; it includes menus and long explanations. A small emergency/loading fallback and shared codec remain bundled. Freeze tools/watch-codec-v2.json and tools/watch-schema.json (retain historical v1) when adding translations; use tools/register_watch_language.py without rebuilding. Native menu literals use generated LK_ IDs; restore canonical text with generate_language_pack.restore_project before editing it, then synchronize.

- Repository packet layout: Packs/App/Languages for dynamic settings and generic LP4 watch packets; Packs/Germany/Languages/<app-version>/ retains historical LP3 packets. Export with tools/export_language_packs.py after synchronization. The phone downloads the schema/codec-compatible selected packet from GitHub and caches only that packet; full developer fixtures live in tools/language-packets.json outside the phone bundle. Publish matching versioned packets before distributing a build.

- All new language packets use Packs/App/Languages; keep archived Germany LP3 files for older builds. The owner explicitly requested removal of the old German compatibility directory. Do not recreate it. The settings list and translations use the dynamic settings-v1 catalogue; an English fallback remains bundled. New settings-only languages require data updates, not PBW builds. DE/EN/ES/FR watch languages use the generic decoder. Additional compatible watch languages need only data; unsupported glyphs or schema/codec changes may require a build. See tools/register_settings_language.py and preserve custom catalogue entries. The v2 resource was explicitly migrated for French in 3.8.49; retain both watchPacks variants and never retrain on registration.

- Compact app persistence starts at 3.8.50: src/c/compact_storage.c/h keeps keys and the booking journal, reads both raw and packed records, migrates in place at startup and skips unchanged values. Keep all five copies identical. Do not install older builds directly on packed records: build/run tools/build_legacy_restore.py first, which restores legacy values before an old build. Source defaults must always be COMPACT_WRITE_DEFAULT 1; only the temporary restore-helper build uses 0. See docs/DEV-3.8.50.md and tests/compact_storage_test.c. The selected language format remains LP4.
